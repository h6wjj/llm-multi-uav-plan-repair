# 第二步：90 个正式实例的冻结记录

正式输入为 `tasks.jsonl`，SHA-256 `abd943e3060b15310627b1f9f701a2ee2930717dc5f6b580dbcba2ddd5f7c238`。本地和虚拟机中的文件哈希一致。当前状态为**90 例三方法正式运行已完成，270/270 行通过正式范围指标审计**。正式结果和分层统计见 `实验数据/results/suffix_grid_three_way_formal_v1/`。

- 因素：链、分支、汇合 × 无、弱、强后缀耦合 × 每格 10 个独立随机布局，共 90 例。正式种子基数为 `20270000`。
- 耦合标签由生成时的几何和解析代价确定，不依据任何方法的执行结果回填。无耦合时 `h2-h3≈0`；弱、强耦合的解析完整后缀差值分别落在预设区间。
- 航点容差 0.10 m，所有任务航段均大于容差的 4 倍；使用 48 Hz VelocityAviary/PyBullet 电机动力学。源数据中不受仿真器支持的天气、禁飞区等特征通过既有投影适配器剔除，不能把这些实例解释为包含这些物理约束的实验。
- 失效时对三种方法复用相同初始计划和物理状态；完整实验统一比较即时局部、CDS-MR 和明确目标的全局重分配。评价项目和汇总规则已固定在 `protocol.json`。

调试预检使用单独的 `preflight_3.jsonl`，种子 `20260924`、`20262124`、`20263124`，与正式 90 例的种子和任务 ID 均无重合；预检文件 SHA-256 为 `9b2606eecc3e357c699e16bf25aba73267ca80dca81ac775654745c0068c6668`。最终三方法预检记录在 `实验数据/results/suffix_grid_three_way_preflight_v3/`。无耦合链例三方法完成时间均为 62.42 s；强耦合分支例局部/完整/全局方法为 75.50/62.27/62.27 s；强耦合汇合例为 75.56/60.88/60.88 s。这只检验运行链与机制，不计入 90 例统计，也不能单独支持总体优势结论。

正式运行按冻结协议完成：三种方法各 90/90 行，均恢复成功且严格满足约束；三方法失效状态配对审计及轨迹、NPSD、耗时和全局最优复算均通过。CDS-MR 相对即时局部的实际修复路径平均降低 10.72%，完成时间降低 8.65%；无耦合组持平，弱/强耦合组出现逐实例正向差异。该 90 例是构造因子实验，第三步的独立任务测试尚未开始。

2026-09-23 运行记录：权威预检结果为 `实验数据/results/suffix_grid_three_way_preflight_v3/metric_audit.json`；正式运行清单为 `实验数据/results/suffix_grid_three_way_formal_v1/run_manifest.json`，正式范围审计为同目录 `formal_metric_audit.json`。v1 因错误失效作废，v2 因调试/正式任务 ID 重合而由 v3 取代。轨迹指标定义为**执行修复命令的无人机在各航点间的实际电机动力学路径长度之和**，不包含空闲无人机的漂移；求解器计算耗时与失效到首个成功修复命令的响应耗时分别报告。三种“结构”改变的是依赖图/因果闭包，执行器仍按 B2→B3→B4 的共同拓扑顺序发出命令，不能解释为三种不同的并行调度时序。原始正式审计文件 `metric_audit.json` 因通用 v1 脚本把 scope 固定标为 `preflight_only` 而保留作原始记录；正式权威版本使用 scope 明确的 `formal_metric_audit.json`。
